# 搬瓦工购买与套餐选择指南：官网访问、机房和下单步骤

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 服务商，提供基于 KVM 架构的海外虚拟服务器。VPS 可以用于建站等需要远程管理服务器的场景；购买之后，用户还需要选择系统、管理账号，并自行处理网站和数据。对于第一次接触 VPS 的读者，选购时除了看价格，也要考虑服务器资源、访问人群所在地区、机房选择和自己能接受的付款周期。

这篇指南整理参考资料中的官网入口、六种套餐配置和购买流程。表中价格与规格是资料所列信息，并非实时报价；实际可选机房、库存和应付金额请在下单页面核对。

### 从需求而不是名称开始比较

**预算与位置。** 基础款的年付价格在表中最低，适合先看重入门成本、且能接受所列欧美普通机房的读者。它与同为 1 核、1GB 内存、20GB SSD 的 GIA-E 入门款，主要区别并不在这三项配置，而在价格、线路和可选机房。不要只比较硬盘大小后便认为两者适用于完全相同的访问需求。

**资源与流量。** GIA-E 标准款相较入门款增加了处理器核心、硬盘和月流量，但内存仍为 1GB；高配款则列有 4GB 内存和更多硬盘、流量。选择时可以先估计网站程序及数据占用，再看月流量是否符合预期，而不是把核心数当作唯一指标。香港两款之间也有类似取舍：标准款内存、硬盘和月流量更高，价格也更高。

**付款周期。** 表中的基础款列出年付；GIA-E 入门和标准款列有季付与年付；高配及香港两款列有月付与年付。短周期单次投入较小，适合尚未确定长期需求时控制首次支出；年付则应比较整年总费用，确认自己愿意承担更长的付款周期。不同方案提供的周期并不相同，不要假设每款都有月付。

**限量方案。** 参考资料还提及不定期出现的限量套餐，其库存不固定。如果在[套餐总览](https://bit.ly/BanWaGon)看到这类产品，应单独查看配置、机房和计费条件，不能仅凭“限量”判断它与常规款完全相同，也不要把资料中的历史促销情况当作当前报价。

## 机房怎么选：先看访问人群，再看套餐范围

机房位置与线路是两个需要一起考虑的因素。先确定网站或服务的主要访问地区，再结合用户所用运营商、预算及产品页面提供的机房列表缩小范围。表中 GIA-E 方案列有洛杉矶 DC6/DC9、日本软银和荷兰等机房；香港方案则包括香港及多个 CN2 GIA 机房。基础款的选择范围不同，不能默认所有套餐都能选到同一个地点。

参考资料按运营商给出了一些方向：电信用户可关注洛杉矶 DC6 CN2 GIA-E，联通用户可关注日本软银或荷兰机房，移动用户可关注资料中提到支持 CMIN2 的 DC6。它们可以作为查看产品选项的起点，而不是对每条网络路径、延迟或稳定性的保证。地理位置、访问网络和使用时段都可能影响实际连接；套餐标示的 1Gbps 或 2.5Gbps 也不能直接换算成个人访问速度。

香港方案的价格在所列方案中明显更高。若主要用户集中在附近地区，可以把香港作为比较对象，但仍要结合实际预算、流量需求和页面提供的机房选项判断，不能只凭物理距离决定。若服务面向其他地区的访客，也应考虑那些访客的位置，而非只看自己连接服务器的方便程度。

参考资料称 CN2 GIA-E 可通过 KiwiVM 切换机房，并称迁移需要重装系统。计划迁移前，应先保存网站文件、数据库和必要配置，确认备份可用，再查看面板中实际可选的目标机房及迁移提示。重装会影响现有系统环境，不应把切换机房当成无需准备的简单改动；具体条件以购买页面和面板显示为准。

1. **打开入口并查看产品。** 从[全部套餐页面](https://bit.ly/BanWaGon)进入，或者使用上表对应的购买链接。先确认产品系列、资源、可选地区和计费周期，避免因名称相近而选错。
2. **注册账号。** 按页面提示提供可收信的邮箱、密码及账单资料。保存好账号信息，并核对账单国家或地区等内容；资料显示会影响税率，最终金额应以结账页面为准。
3. **选择方案和机房。** 用预算、内存、硬盘、月流量和访问人群位置进行比较。若看重以后调整机房，先核对所选产品包含哪些地点以及面板提供的操作条件。

6. **查收邮件并登录控制面板。** 参考资料称购买后的邮件包含 VPS IP 和 KiwiVM 后台链接。收到后核对服务器信息，登录面板，熟悉系统重装、快照等功能的位置，不要在尚未理解其影响时执行会改变系统或数据的操作。
7. **准备远程连接。** 参考资料介绍可在 KiwiVM 中设置管理员密码，再通过 SSH 连接服务器。连接时使用收到的服务器信息，并妥善保管密码；后续部署网站前，先确认所选系统和自己的管理需求。

## 下单前后常见问题

### 季付和年付怎样比较？

先确认具体套餐是否同时提供两种周期，再比较各自的单次付款金额和一年内计划使用的时间。以资料所列 GIA-E 入门款为例，季付是 $49.99，年付是 $169.99；两者的选择不仅取决于价格，还取决于是否已经确定长期使用。续期金额及可选周期应在产品和账单页面确认。

### 订单被拒绝，应该先检查什么？

先核对账单资料、支付信息以及访问环境。参考资料提到，访问 IP 所显示的地区与账单地址不一致可能触发风控。如果页面提供了进一步的处理提示，应按提示操作；这些检查只能帮助排查明显问题，不能保证订单一定通过。

### 系统重装和迁移前为什么要备份？

重装系统会改变现有系统环境，参考资料也提示机房迁移需要重装。已有网站、数据库或配置时，先把需要保留的数据另行保存，并确认可以找到和恢复这些内容。KiwiVM 的快照功能可以纳入操作准备，但应先理解面板显示的具体使用条件。

### 退款、优惠和库存如何确认？

这些条件可能随产品、活动及时间变化。购买前查看当前产品和结账页面的适用条款；如涉及退款，也应先确认当时的政策及适用条件，不要把历史资料中的具体说法视作无条件承诺。遇到价格、库存或机房选项与上表不一致时，以实际页面信息为选购依据。
